# 🚀 Algorithms in C

Welcome to my C programming workspace!

This repository is a collection of my coursework and personal algorithmic challenges at Politecnico di Torino. It is where I translate theoretical computer science concepts into functional C code, battling through memory leaks, pointer logic, and the compiler along the way.

*(Spoiler alert: Once I survive this collection of algorithms, a sequel repository called `Algorithms-in-C-Advanced` will be born for the next level of data structures).*

## 🧠 Topics & Algorithms Covered

This repository bridges the gap between algorithmic theory and practical implementation. The code here explores:

*   **Theoretical Foundations:** Analysis of P vs NP, Online Connectivity Problems, and introductory Graph Theory concepts.
*   **Basic Sorting:** Implementation of Selection Sort, Bubble Sort, and Insertion Sort.
*   **Optimized Sorting:** Shell Sort (specifically utilizing Knuth's sequence) and Bottom-Up Merge Sort.
*   **Non-Comparison Sorting:** Fast integer sorting using Counting Sort and Radix Sort.
